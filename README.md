# 慢点外卖 · Slow Bite

自用外卖模拟 PWA。选餐、购物车、模拟下单后，商家接单、制作、骑手接单、配送、送达依次推进。订单不会发送到真实外卖平台。界面按用户提供的美团外卖截图重做，内置10家示例店铺、独立菜单、商品规格、商家搜索与筛选、优惠券、购物车、结算和配送详情。

**在线使用：** https://miaodidi.github.io/slow-bite-pwa/

## iPhone 安装

用 Safari 打开上方链接 → 分享 → 添加到主屏幕 → 如有“作为 Web App 打开”选项，保持开启。

首次联网打开完成缓存后，菜单与订单支持离线使用。进度根据下单时间计算；锁屏或切换微信再回来，会恢复到当前进度，不依赖后台定时器持续运行。本版没有后台推送或锁屏实时活动。已在 Xcode 的 iPhone 18 Pro / iOS 27.0 模拟器检查 Safari 和主屏幕独立 Web App 的显示；实体手机和微信跳转仍需真机验证。

## 微信与个人收款

本版提供两种选择：纯模拟，以及手动微信转入。

手动流程：在“我的 → 支付设置”中填写收款人备注并导入收款码图片 → 创建模拟订单 → 复制金额 → 自己打开微信并选择联系人转账，或扫一扫从相册识别收款码 → 返回模拟订单。

- PWA 无法读取微信好友、预选联系人、用个人收款码创建支付订单，或自动查询到账和退款。
- `weixin://` 仅尝试打开微信，可能被 iOS/Safari 拦截。不能依赖它跳到指定收款页。
- 同一台手机可以尝试长按图片存储后从微信相册识别；是否允许付款取决于微信、收款码和账户状态。
- 不能把付款给同一微信账号自己的收款码作为已验证方案。
- 返回 PWA 只继续模拟流程，**不代表支付成功**。本项目没有资金托管、自动扣款或自动退款。
- 真实付款必须自己在微信确认；没有在测试中执行真实转账。

2026-11-19 核对的官方资料：微信的[个人收款（二手交易场景）](https://pay.weixin.qq.com/doc/v3/partner/4012602287)基于平台收付通，当时文档标注内测，需要平台接入和个人收款方授权；[开发指引](https://pay.weixin.qq.com/doc/v3/partner/4012602295)要求平台商户号、AppID、证书和服务端验签查单。它不是对任意个人 PWA 开放的朋友转账接口。

## 数据与部署

订单、地址、购物车、联系人备注和导入的收款码保存在当前浏览器的 localStorage，不上传 GitHub。清理网站数据或卸载可能丢失记录；“我的”中可以导出订单 JSON。收款码只本地导入，不要提交进仓库。站点代码与 GitHub Pages 地址是公开的，其他访客有各自的本地记录。

纯静态，无运行时第三方脚本、字体、支付网关或分析服务。商家和分类图片裁切自用户提供的两张界面参考，随站点本地缓存；商品照片用于示意，并非完整真实菜单。商家价格、销量、评价、地址和配送地图都是静态示例数据，没有接入美团接口。应用图标为独立绘制。GitHub Actions 仅部署静态文件白名单。

## 开发

```sh
python3 -m http.server 4174
node --check app.js
npm test
```

访问 http://localhost:4174 。推送 main 后自动部署 Pages。静态资源发生变化时须更新 sw.js 的缓存版本。

## 界面与操作

- 首页：黄色顶部、双排分类、神抢手 / 拼好饭促销、商家列表、神券浮条和四栏导航。
- 店铺：商品分类导航、杯型 / 冰量 / 甜度、购物车数量、起送价校验，跨店选购需要明确清空原购物车。
- 结算：本机收货地址、订单备注、餐具、优惠抵扣、虚拟余额或微信手动转账。
- 订单：六阶段时间状态、配送路线示意、进度明细、取消、收货和再来一单。
- 我的：支付设置、送达时长、记录导出和模拟原理说明。首页与下单主流程不反复展示说明。

旧版的 `slowbite.orders.v1` 与 `slowbite.settings.v1` 数据保持兼容。商家和菜品不是实时数据，付款给自己、微信跳转与 iPhone 安装行为仍需用户真机验证。

`npm test` 覆盖后台恢复后的状态、旧数据兼容、规格购物车、跨店保护、起送价、优惠边界和小数金额、订单持久化、微信未核验状态、搜索筛选与离线资源完整性。

## iPhone 18 Pro 屏幕适配

本项目按个人设备的 1206 × 2622 像素截图（402 × 874 CSS 像素，3×）设计，使用竖屏布局。实际上下安全区由 iOS 的 `env(safe-area-inset-*)` 提供，不在产品代码里写死状态栏高度。

`viewport-fit=cover` 与 `black-translucent` 让页面背景延伸到状态栏下方；根页面、主题色和顶部安全区采用同一页面颜色，避免 iOS 把灰色 body 背景绘成白条。标题与导航保留安全距离，不画假的时间、电池或状态栏。底部只增加一次系统手势安全区。

这次验证包含主屏幕添加、独立启动、首页 / 神券 / 我的切换和商家列表滚动。安装在旧系统 Web Clip 中的状态栏配置可能被 iOS 保留；先完全关闭并重新打开。如仍旧样式，可在 Safari 再添加一个主屏幕入口进行对照，勿先清理网站数据。
