# 慢点再吃 · Slow Bite

自用外卖模拟 PWA。选餐、购物车、模拟下单后，商家接单、制作、骑手接单、配送、送达依次推进。订单不会发送到真实外卖平台。内置六份虚构菜单，是可试用的首版原型。

**在线使用：** https://miaodidi.github.io/slow-bite-pwa/

## iPhone 安装

用 Safari 打开上方链接 → 分享 → 添加到主屏幕 → 如有“作为 Web App 打开”选项，保持开启。

首次联网打开完成缓存后，菜单与订单支持离线使用。进度根据下单时间计算；锁屏或切换微信再回来，会恢复到当前进度，不依赖后台定时器持续运行。本版没有后台推送或锁屏实时活动。实际 iPhone / 微信跳转尚需真机验证。

## 微信与个人收款

本版提供两种选择：纯模拟，以及手动微信转入。

手动流程：在“冷静金”中填写收款人备注并导入收款码图片 → 创建模拟订单 → 复制金额 → 自己打开微信并选择联系人转账，或扫一扫从相册识别收款码 → 返回模拟订单。

- PWA 无法读取微信好友、预选联系人、用个人收款码创建支付订单，或自动查询到账和退款。
- `weixin://` 仅尝试打开微信，可能被 iOS/Safari 拦截。不能依赖它跳到指定收款页。
- 同一台手机可以尝试长按图片存储后从微信相册识别；是否允许付款取决于微信、收款码和账户状态。
- 不能把付款给同一微信账号自己的收款码作为已验证方案。
- 返回 PWA 只继续模拟流程，**不代表支付成功**。本项目没有资金托管、自动扣款或自动退款。
- 真实付款必须自己在微信确认；没有在测试中执行真实转账。

2026-11-19 核对的官方资料：微信的[个人收款（二手交易场景）](https://pay.weixin.qq.com/doc/v3/partner/4012602287)基于平台收付通，当时文档标注内测，需要平台接入和个人收款方授权；[开发指引](https://pay.weixin.qq.com/doc/v3/partner/4012602295)要求平台商户号、AppID、证书和服务端验签查单。它不是对任意个人 PWA 开放的朋友转账接口。

## 数据与部署

订单、联系人备注和导入的收款码保存在当前浏览器的 localStorage，不上传 GitHub。清理网站数据或卸载可能丢失记录；设置中可以导出订单 JSON。收款码只本地导入，不要提交进仓库。站点代码与 GitHub Pages 地址是公开的，其他访客有各自的本地记录。

纯静态，无运行时第三方脚本、字体、支付网关或分析服务。菜单图片使用系统 Emoji；图标为原创图形。GitHub Actions 仅部署静态文件白名单。

## 开发

```sh
python3 -m http.server 4174
node --check app.js
node --test tests/order-state.test.cjs
```

访问 http://localhost:4174 。推送 main 后自动部署 Pages。静态资源发生变化时须更新 sw.js 的缓存版本。
