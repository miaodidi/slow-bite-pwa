# Slow Bite · 慢点再吃

一个给自己用的外卖冷静期 PWA：可以把“想吃”变成一笔**模拟订单**，进入一段可配置的冷静期；冷静期结束后，再决定是否去真实外卖平台下单。

## 设计边界

- 默认订单完全是本地模拟，不会创建真实外卖订单，也不会扣款。
- “微信冷静金”仅支持展示你自己配置的收款码并打开微信；PWA 无法确认微信转账是否成功，也不会把“已返回页面”当成支付成功。
- 菜单、订单和设置保存在当前设备浏览器的 `localStorage` 中。
- 项目不使用美团/饿了么的私有接口、Logo 或受版权保护的页面素材。

## 本地运行

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。在 iPhone 上，可把部署后的地址通过 Safari 的“添加到主屏幕”安装为 PWA。

## GitHub Pages

仓库是静态文件，可直接用 GitHub Pages 部署。开启 Pages 后，访问地址即可在 Safari 中添加到主屏幕。
